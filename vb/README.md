# VELVET & BEAN

Одностраничный сайт специализированной кофейни: меню и заказ, корзина, бронирование, клуб лояльности.
Языки: қазақша, русский, English. Валюта меняется вместе с языком (₸ / ₽ / $).

Один файл `index.html`, без сборки и зависимостей. Откройте его в браузере.

Курсы валют задаются в массиве `CUR` в начале скрипта (`r` — единиц валюты за 1 $).
